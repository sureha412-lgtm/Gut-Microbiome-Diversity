Project Overview

This project applies machine learning techniques to investigate gut microbiome profiles from Healthy and Inflammatory Bowel Disease (IBD) groups. The workflow includes preprocessing, feature analysis, machine learning classification, model evaluation and biological interpretation.

Machine Learning Models

Random Forest

Ensemble of decision trees used for nonlinear classification and feature importance analysis.

SVM

Support Vector Machine using an RBF kernel for classification in a high-dimensional feature space.

XGBoost

Gradient boosting model that builds sequential decision trees to improve predictive performance.

Neural Network

Feed-forward neural network used to model nonlinear relationships within the microbiome data.

Interactive Dashboard

The deployed dashboard provides interactive exploration of Healthy versus IBD feature distributions, model evaluation, ROC-AUC analysis, confusion matrices, feature importance and biological interpretation.
